# Wildwise

[English](README.md)

Wildwise 是《**饥荒联机版**》的综合便利模组，将物品与生物信息、战斗血条、协作地图、自动整理、行为队列、智能小木牌和牛状态栏整合在一起。沿用游戏原有的界面风格，支持键鼠操作、简体中文和英文。

> 当前为 **0.2.0 开发版**，尚未完成图形客户端及真实多人联机验证。已知限制见下文，详细验证情况见[测试报告](docs/testing.md)。

## 功能介绍

### 查看物品、生物和世界信息

将鼠标移到目标上，即可查看适用的血量、基础伤害、食用效果、保鲜度、装备耐久、燃料和加工进度等信息。食用效果会考虑当前角色；农作物、随从也有对应的生长和状态信息。

按住游戏的检查修饰键可展开详情，菜单提供简洁、标准、详细三种显示预设。还可查询四格食材的料理结果；容器内容、同类物品定位、世界事件详情和攻击范围数值需要房主允许。

### 战斗血条

血条根据生物当前的战斗目标显示，默认关注敌视自己的生物，也可扩展到随从或附近队友的战斗。默认最多显示 **12 条**，脱战后保留 **2 秒**，数量、缩放和数值显示可配置。

生物头顶已有可见血条时，鼠标提示会省略重复的血量；血条未显示时，仍可通过鼠标查看。

### 协作地图

在地图上查看队友的位置与名称，共享探索进度，并为实际穿越过的虫洞记录配对编号。配对以颜色和编号区分，未探索的端点仍受迷雾限制。队友在其他世界时显示其所在世界。

地图支持位置、危险、资源、集合四种临时标记，每人最多 **5 个**，**60 秒**后消失。玩家可清除自己的标记，管理员可清空全部标记。向营火加入木炭可发出信号火提示；屏外队友指示默认在查看玩家列表时出现。

### 自动合堆与拾取

附近新掉落的同类物品会在落地后自动合堆。默认保留玩家主动丢在地上的物品和读档恢复的地面摆设。

自动拾取需单独开启，默认只拾取背包已有的同类物品。多人同时符合拾取条件时，优先分配给距离最近的玩家；背包只能装下一部分时，余量留在地面。

### 行为队列与批量布点

用 `Shift` 配合点击或拖动，为采集、砍伐、采矿、农业和适用的设施操作添加目标，也可重复制作非建筑配方。默认最多 **200 个任务或布点**。

工具损坏时会尝试使用库存中的替代工具；材料耗尽、背包已满或角色状态不支持时暂停。你可以随时移动、普通点击或攻击来接管角色，取消后续任务。

手持材料或装备锄头后，`Shift`＋右键拖动可创建区域布点预览，再点击“执行布点”开始。农田支持 **2×2、3×3、4×4** 布局，地皮和墙体按原版规则对齐；无效点用叉号标示。普通单次建筑放置保持游戏原有操作。

### 智能小木牌

为箱子、冰箱、盐盒、切斯特和哈奇等支持的容器显示内容图标，以第一格非空物品为准。包裹可显示内部首件物品，容器清空后不保留旧图标，方便辨认基地里的储物位置。

### 牛状态栏

骑乘牛时查看生命、驯化、顺从、倾向、鞍具剩余次数、饥饿和预计骑乘剩余时间。按 `B` 可切换显示，也可在菜单中调整面板位置和饥饿显示阈值。

## 安装

Wildwise 由房主在“服务器模组”中启用，**服务器和每位玩家都需要安装相同版本**。当前通过 GitHub 分发，需要手动安装。

1. 打开 [GitHub Actions](https://github.com/Morilence/Wildwise/actions)，选择一次成功的构建，在 **Artifacts** 中下载 `Wildwise-mod`。
2. 解压下载的构建产物，再将里面的 `Wildwise-0.2.0.zip` 解压到游戏的 `mods` 目录，确认文件位置为：

   ```text
   Don't Starve Together/mods/Wildwise/modinfo.lua
   ```

3. 在建房界面的“服务器模组”中启用 Wildwise，根据需要配置后启动世界。
4. 进入游戏后，点击 HUD 上的 **Wildwise** 按钮或按 `F7` 打开设置。

独立专服维护者可使用下方的 [modoverrides.lua 完整配置示例](#modoverrideslua-配置示例)。Master 与 Caves 需安装同一版本，并分别配置。

## 常用操作

| 输入 | 操作 |
|---|---|
| HUD 按钮／`F7` | 打开设置菜单 |
| 游戏检查修饰键 | 展开鼠标提示详情 |
| `Shift`＋单击 | 添加一个操作目标 |
| `Shift`＋双击 | 选择附近同类可操作目标 |
| `Shift`＋左键拖动 | 框选区域内的目标 |
| `Shift`＋右键拖动 | 对手持材料或锄头创建批量布点预览 |
| `Shift`＋点击制作配方 | 重复制作非建筑配方 |
| 移动、普通点击、攻击 | 接管角色并取消队列 |
| 队列面板 | 暂停、继续、清空 |
| `Alt`＋地图主操作键 | 创建当前选定类型的标记 |
| `B` | 切换牛状态栏 |

菜单键、队列修饰键和牛状态快捷键可在设置中重新绑定，主操作键跟随游戏绑定。打开聊天、地图、菜单或切出游戏窗口会暂停队列，返回后需主动点击“继续”。

## 配置与默认行为

`F7` 菜单分为**信息、地图、物品、队列、诊断**五个页签。房主控制公共规则和可用功能，玩家在允许范围内调整自己的显示和操作偏好。个人显示设置立即生效，服务器模组配置修改后需重启世界。

| 设置 | 默认行为 |
|---|---|
| 信息显示 | 标准预设，可调整类别、字号和缩放 |
| 容器内容、世界事件详情、攻击范围数值 | 关闭，由房主允许后使用 |
| 新掉落合堆 | 开启 |
| 主动丢弃物、读档地面物品合堆 | 关闭 |
| 自动拾取 | 关闭，需房主允许且玩家个人开启 |
| 拾取条件 | 默认只拾取已携带的同类物品 |
| 位置与探索共享 | 生存／无尽模式开启，荒野／PvP 关闭 |
| 屏外队友指示 | 查看玩家列表时显示 |

**开启自动拾取：**房主先在服务器模组配置中打开“允许玩家开启自动拾取”并重启世界，玩家再进入 `F7 → 物品`，打开“自动拾取”。

**调整共享：**在 `F7 → 地图` 中分别设置自己的位置与探索共享。关闭后停止后续共享，已被队友学到的探索无法撤回。被服务器规则或功能冲突停用的选项会显示原因。

### modoverrides.lua 配置示例

通用项（语言、界面缩放、菜单按键、诊断）放在最前，其余按功能模块排列。DST 原生配置使用平铺字段，因此模块项带有明确前缀，例如 `beefalo_hunger_threshold`。本节代码可直接用于原生配置文件，无需额外脚本。旧配置字段不再读取，旧版的本地个人设置不会自动迁移。

下面列出全部 **30 个服务器模组配置项**，赋值均为默认值，注释说明用途和可选值。建房界面的 Wildwise 配置也使用这些选项。布尔值 `true` 表示开启、`false` 表示关闭；布尔值和数字不加引号，字符串保留引号。

将配置写入存档集群的 `Master/modoverrides.lua`；有洞穴时，同样配置 `Caves/modoverrides.lua`。已有文件时，把 `["Wildwise"]` 条目合并到原来的 `return` 表中，保留其他模组条目；如果已存在 Wildwise 条目，直接修改它。`Wildwise` 必须与手动安装的模组目录名一致。

```lua
return {
    ["Wildwise"] = {
        enabled = true, -- 是否启用整个模组：true / false
        configuration_options = {
            -- 通用设置
            language = "auto",                  -- "auto" 跟随游戏 / "zh" 简体中文 / "en" 英文
            ui_scale = 1,                       -- HUD 缩放倍数：0.75 / 1 / 1.25 / 1.5
            menu_key = 288,                     -- 菜单按键：287＝F6 / 288＝F7 / 289＝F8
            diagnostics = false,                -- 预留诊断日志开关：true / false；当前不影响日志输出

            -- 信息洞察
            info_enabled = true,                -- 物品、生物与世界信息；true / false
            info_container_contents = false,    -- 允许容器内容查询与同类物品定位；true / false
            info_world_events = false,          -- 允许世界事件详情；true / false
            info_attack_range = false,          -- 允许攻击范围数值；true / false
            info_font_size = 22,                -- 信息字号：18 / 22 / 26 / 30

            -- 战斗血条
            healthbars_enabled = true,          -- 战斗血条；true / false
            healthbars_limit = 12,              -- 同时显示的血条数：4 / 8 / 12 / 16 / 20
            healthbars_linger_seconds = 2,      -- 脱战后保留秒数：0 / 1 / 2 / 3 / 5
            healthbars_scale = 1,               -- 血条缩放倍数：0.75 / 1 / 1.25 / 1.5
            healthbars_numbers = true,          -- 显示血量数值：true / false
            -- "self"：仅自己；"followers"：自己及随从
            -- "nearby"：附近玩家；"nearby_followers"：附近玩家及随从
            healthbars_hostile_scope = "self",  -- 血条敌意判定范围

            -- 地图协作
            map_enabled = true,                 -- 地图协作；true / false
            -- 共享规则："auto" / "on" / "off"
            -- "auto"：生存、无尽模式开启；荒野或 PvP 关闭
            -- "on"：允许共享，仍尊重玩家的个人开关；"off"：禁止共享
            map_share_position = "auto",        -- 位置共享
            map_share_exploration = "auto",     -- 探索共享

            -- 物品整理
            items_enabled = true,               -- 自动合堆与拾取服务；true / false
            items_stack_world = true,           -- 合堆新掉落的物品；true / false
            items_stack_manual = false,         -- 合堆玩家主动丢弃的物品；true / false
            items_stack_loaded = false,         -- 合堆读档恢复的地面物品；true / false
            items_pickup_allowed = false,       -- 允许玩家在 F7 → 物品中开启自动拾取；true / false
            items_pickup_existing = true,       -- 拾取仅限已携带的同类物品；false 取消此条件；true / false
            items_radius = 4,                   -- 合堆／拾取半径（游戏距离单位）：2 / 4 / 6 / 8

            -- 行为队列
            queue_enabled = true,               -- 行为队列与批量布点；true / false
            queue_farm_grid = 3,                -- 每块农田的布点：2＝2×2 / 3＝3×3 / 4＝4×4

            -- 智能小木牌
            signs_enabled = true,               -- 智能小木牌；true / false

            -- 牛状态栏
            beefalo_enabled = true,             -- 牛状态栏；true / false
            beefalo_hunger_threshold = 15,      -- 牛饥饿显示激活阈值（饥饿值）：0 / 5 / 15 / 25
        },
    },
}
```

可只保留需要覆盖的配置项；未写出的项沿用游戏已保存的配置或模组默认值。修改后重启对应世界；地上与洞穴需要相同规则时，在两处保持相同配置。

F7 菜单保存玩家个人偏好，不会改写 `modoverrides.lua`。服务器功能开关和权限始终生效，例如 `items_enabled = false` 会停用物品整理，即使 `items_pickup_allowed = true` 也不会自动拾取。显示相关配置提供个人设置的初始值，不会强制覆盖玩家已保存的偏好。

## 兼容与限制

Wildwise 不依赖其他便利模组。检测到已知的同功能模组时，会停用自身对应的重叠功能并提示；具体列表见[功能与兼容说明](docs/features.md)。

当前版本仍需验证图形界面、真实多人联机、地上地下往返，以及与 Geometric Placement、Minimap HUD、Combined Status 等模组的组合。部分皮肤、调味物品和包裹的小木牌外观也尚未完成客户端验证。未知物品或角色的部分信息可能无法显示。

行为队列不提供自动选敌、自动战斗或躲避攻击；手柄完整操作暂不支持。详细功能边界与验证状态见[功能覆盖表](docs/features.md)和[测试报告](docs/testing.md)。

## 维护与开发

源码使用 Lua 5.1。开发和打包需要 Lua 5.1（含 `luac`）、LuaRocks、Python 3 和 Node.js 24；安装这些工具后，在仓库目录运行：

```sh
luarocks --lua-version=5.1 install luacheck 1.2.0-1
luarocks --lua-version=5.1 install lua-cjson 2.1.0.10-1
npm ci
npm run check
npm run package
```

安装包输出到 `dist/`。模块说明见[架构文档](docs/architecture.md)，专服测试方法见[测试文档](docs/testing.md)，参考来源见[调研记录](docs/research.md)。代码采用 [MIT 许可证](LICENSE)，游戏资源与其他作品的权利见[第三方说明](THIRD_PARTY_NOTICES.md)。
