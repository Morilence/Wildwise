# 架构与关键实现

一个服务器启用、全部客户端加载的 Lua 包。`modmain.lua` 只读取配置并注册；专服执行世界服务，客户端额外加载输入与 UI。

| 层 | 文件 | 数据归属与职责 |
|---|---|---|
| 公共能力 | `core/config`, `protocol`, `map_transfer`, `ordered_index`, `lru`, `lifetime`, `hooks` | 配置与冲突规则，受限消息与原子分片，有序空间桶，256 项 LRU，监听释放，保留原函数语义 |
| 服务端协调 | `components/wildwise_world` | 玩家会话、权限、订阅、动作结果与分世界状态；委托 map_sync 调度传输 |
| 实体信息 | `services/facts`, `observer`, `health` | 公共字段和查看者字段分别缓存；健康状态一份事实，多个显示入口 |
| 物品 | `services/items`, `runtime/items` | 规则与事件适配分离；来源、落地、空间索引、预算处理、原版库存语义、队列预留 |
| 地图 | `services/map`, `map_sync` | 获准探索的来源日志、标记、稳定配对编号、版本化保存；频道快照、共享编码、预算发送 |
| 队列 | `services/queue`, `planner`, `runtime/actions` | 一次一个动作、世代 token、原版动作路径、平台坐标、失败与恢复 |
| 容器与骑乘 | `services/containers`, `services/signs`, `runtime/signs`，facts 的 beefalo 分类 | 原生辅助牌的事件生命周期，牛状态复用观察服务 |
| 界面 | `ui/*`, `runtime/client`, `runtime/input` | 设置、显示缓存、控件、hover、地图、主动血条、牛状态、预览 |

## 配置边界

配置分为原生入口、运行时规则和个人偏好。`modinfo.lua` 的 74 个公开选项保持 DST 要求的平铺标量，例如 `beefalo_hunger_threshold`；`core/config.load` 将其转换为 `config.beefalo.hunger_threshold`。语言、HUD 缩放、菜单按键和诊断项在根节点，其余归入 `info`、`healthbars`、`map`、`items`、`queue`、`signs`、`beefalo`，模块内部不重复前缀。非法类型或枚举值回退默认值并在启动时记录字段名。预算、观察范围等内部常量不通过原生配置暴露。

`Config.settings` 单独构造个人偏好，模块表深拷贝，不与服务器规则或其他客户端共享可变引用。F7 使用 `beefalo.hunger_threshold` 这样的模块路径读写和发送个人偏好；服务器仍检查自身权限。个人设置存入 `wildwise_client_v2`，不读取或迁移旧平铺键。地图共享开关由当前世界保存并在握手时同步，本地偏好加载不会覆盖它们。

小木牌在 `signs` 下按容器 prefab 分别配置，例如 `signs.chester` 对应原生键 `signs_chester`；模块总开关与类型开关同时生效。仅为开启的类型注册 prefab 回调，关闭的容器不挂载监听或辅助牌。木箱、龙鳞宝箱和远古船货舱默认开启，其余已支持类型默认关闭。

`tests/config_spec.lua` 核对原生选项、内部路径、全部可选值及两份 README 的默认示例，也验证关闭项、零阈值、非法输入、嵌套对象隔离与 RPC 编解码。

## 观察、通信与权限

客户端按实体合并 hover、血条、菜单及牛状态需求，每两秒续租。服务器每个实体只维护一个 healthdelta 监听；公共事实最多每 500 ms 更新，健康变化在 100 ms 周期内合并。查看者的角色、饮食与食物记忆不共享缓存。没有订阅者即清理记录与监听。

`facts` 按战斗、食物、装备、加工、农业、随从、牛分组登记读取器，逐组在故障边界内读取。一个组件抛错时丢弃该组不完整输出，保留其他组；健康专用路径和查看者路径也有相同保护。诊断只维护固定读取器集合的计数／首次摘要，开启配置后每类首次失败记日志，避免逐实体逐帧刷屏。这是信息展示的降级边界，不会吞掉物品转移或动作执行异常。由仅血量订阅升级为 hover 时立即刷新公共事实，不等待旧缓存过期。

每条消息携带协议版本、会话、递增序号及受限 JSON 数据。会话含分世界身份、服务器启动时间及递增会话序列。相同 nonce 的 hello 重试保持幂等，不回拨入站序号；HUD 重建的新 nonce 轮换 session，释放旧订阅、动作观察、物品预留与地图发送状态。旧动作回调校验创建时的 session，最近 16 个退役 nonce 防止迟到握手切回旧实例。单包最多 12,000 字节，限制递归层级、节点、字符串与数值；每玩家令牌桶限制请求。独立于 JSON 的实体 RPC 参数先检查类型与有效性，再验证距离、光照／可见性、容器权限与开关。GUID 不进入持久配对 ID。

地图变化合并到最多 250 ms 一次，玩家位置、标记、信号火、配对各有独立版本，未变化频道不重发。动态频道比较固定标量；配对视图按 revision／查看者权限缓存，可见性相同的玩家共享不可变载荷。改变共享属性时替换记录，已排队快照不会被原地修改。

`map_sync` 独立持有 desired／active／applied：分别表示最新需求、发送中的版本和已成功提交传输的版本。每次 Tick 准备目标为 1 ms、最多 32 步，每步最多编码 12 条；总准备与发送目标为 2 ms，同时限制 8 包／24,000 字节，轮转玩家及频道。全部分片预检成功后才开始发送，失败停在当前包重试；权限或版本变化立即作废旧流。离线、退出或会话重建清理接收者，无订阅任务被回收。单次序列化／引擎调用不能中途抢占，2 ms 不是整个世界 Tick 的硬上限。

`map_transfer` 按频道验证 begin／chunk／end 的版本、索引与数量；客户端各频道独立组装，完整后只替换对应频道，位置更新不会清除配对或打断其接收。缺片／重片保留上个完整频道。传输成功表示本机 RPC 提交成功，未增加远端 ACK；沿用引擎 RPC 路径。协议仍为内部版本 1，要求客户端与服务器加载同一份模组，不承诺混合旧客户端兼容。跨 shard 消息只传身份与所在世界。未发送的客户端输入不是服务器事实，客户端不能指定任意 prefab 生成。

事实字段按 schema 类型校验，服务端和客户端均执行；单字段文本最多 240 UTF-8 字节，合计最多 960 字节，完整字符边界截取，并为 JSON 最坏转义留余量。schema 排序在模块加载时完成。health 订阅只筛选两个有限数值，常态无变化时跳过字段计算；500 ms 轮询兜底、healthdelta 和失败重试仍保留。每次 snapshot 必须携带当前用途的完整字段，delta 才发送变化与删除项。Observer 只有在传输返回成功后才推进已发送快照；失败重试以该快照重新比较，短暂变化恢复到原值后退出重试。

公共读取器与四类查看者读取器分别有异常边界。新增模块应声明字段类型、分类、单位和读取归属；不要把个人食用修正放入多人公共缓存，也不要让一个组件报错擦掉其余个人信息。诊断每类首次失败记录摘要，之后只累计计数。

料理请求明确四格食材及锅类型，使用当前原版配方；回调获得独立输入副本，任一配方异常返回“无法确认”，不假报低优先级结果。界面切换材料或锅类型会作废旧请求，响应携带请求编号，防止高延迟下显示上一组材料的菜。容器定位经统一权限检查，使用公开主存储／包裹快照，访问预算 2,048、最多 40 个结果，不生成内容物。

同世界虫洞取消由玩家 `wormholetravel` 触发；跨 shard 迁移由世界 `ms_playerdespawnandmigrate` 触发，只取消相应玩家。客户端取消／失焦递增输入代次，旧鼠标按下不能在旅行后建立任务。骑乘时没有原生动作则暂停，不循环装备工具强行工作。

## 物品守恒与性能

事件提供来源后入有界队列。主动丢弃、读档、未知物品默认既不作为来源也不作为目标。处理前检查落地状态、速度、高度、可拾取、存活物、投射物、陷阱和平台。

`runtime/items` 只解释引擎事件，`services/items` 决定能否处理。读档 opt-in 限定在原版 `POPULATING` 阶段调用的 `EntityScript:SetPersistData`，完成后延迟一帧，不按“实体创建”猜测恢复来源；运行期解包也调用 SetPersistData，但不能因此标成读档物。回调不得覆盖明确的主动丢弃／掉落。允许自动拾取只让新掉落进入候选队列，合堆仍分别检查来源和目标的堆叠权限。

已处理的可合堆物按 prefab、皮肤、平台与空间格子索引；满堆移出候选索引。船用局部坐标分桶，落地／再次入包会更新索引。每 100 ms 最多处理 16 个候选，同时以约 2 ms CPU 时间限制单次批处理；单个原版调用不能被中途抢占。队列容量 2,048，溢出保持原版物品原样，累计 dropped 计数，不销毁物品。

桶内部用来源序号 AVL 索引，插入、删除与后继查询均为 O(log N)。每次合并尝试从相邻九桶选出最早后继，不构造全部邻居数组或重新排序。单个候选最多尝试 64 个邻居，并在每次尝试前检查同一批处理截止时间；未完成时保存来源序号和位置游标，下一 Tick 继续。实体删除、入包或重新标记会清理游标；每次转移前仍复查来源、距离、平台与预留，数量守恒交由原版 Get／Put／GiveItem 保证。

自动拾取先计算库存容量，用原版 Get 拆出可容纳部分，然后 GiveItem；余量保留原实体。堆叠和拒收归还均调用原版 Put，属性合并由游戏决定。队列正在操作的拾取目标带短租约；队列取消／完成释放，长途移动续租。已销毁的引用不再发 RPC，客户端自然跳过；仍存活的部分转移可通知调整目标。

## 队列与接管

显式白名单限制为非战斗便利动作。目标按点击顺序或邻近顺序处理；批量点采用往返顺序。验证时只选已有工具与同类材料，不自动制造工具。实例不存在时跳过，材料／容量／角色状态不支持时暂停，无进展五秒重验一次。

双击和区域选取先过滤 prefab／区域、动作合法性及已排队目标，再按剩余容量 K（最多 200）选取距离起点最近的目标；有界最大堆选择后才进行贪心最近邻规划。规划内部缓存坐标，复杂度 O(N log K + K²)、额外空间 O(K)；引擎 FindEntities 的返回数组与动作选择成本仍存在。队列结束当前任务时清除等待起点，下一任务获得独立超时窗口。

白名单只约束自动执行。玩家点击攻击等不在白名单的动作时，恢复原版输入并取消队列；原生 placer 不被截获。最新多格晾肉架使用 `dryingrack` 和容器 RUMMAGE：显示最早一格剩余时间，按打开、取成品、挂入鼠标材料的有界状态推进，保留仍在晾晒的物品。不存在的船平台返回 skip，禁止退回上次世界坐标继续部署。

取消递增 generation，旧回调不能恢复执行。手动接管使用原版取消／移动路径；空闲状态不额外发 WALKTO。失焦只暂停一次，打开聊天、地图或菜单也会暂停；关闭不自动恢复。长距离寻路按位置变化判断进展，单纯重复播放动画不能无限延长超时。

农田对齐游戏地块，墙和地皮遵循原版坐标；规划与执行共享同一份点位。船移动时重新投影，执行前再校验。原生轮廓没有跟随鼠标的 placer 组件，避免所有点位移动到同一个鼠标位置。

## 存档与释放

只保存配对、个人共享偏好和允许共享的探索记录。探索日志上限 65,536 点，加入时每次最多回放 8 点，通过原版 RevealArea 学习。没有导出或拼接游戏地图二进制格式，也不会复制房主的私有完整地图。

加载地图时先在临时结构验证版本、世界身份、有限坐标、配对 ID／下一编号、唯一端点、个人偏好及有界连续探索数组，成功后一次提交；保存和恢复均复制可变结构。未知或损坏数据保留原始内容并停止地图修改，避免半迁移覆盖。执行中的动作、临时标记、hover、血条和辅助实体不保存。实体销毁、玩家退出或客户端重建关闭各自 lifetime，取消监听和任务。函数包装保留参数与含 nil 的返回值；有后续包装时只禁用自己的回调。

木牌每个容器只挂一个 lifetime，更新按帧合并且图像签名去重；另用子 lifetime 监听当前首件物品的图像变化与移除。内容切换释放旧监听，清空／烧毁／删除容器释放辅助实体。牌使用原版 minisign 网络数据，非持久、NOCLICK／FX，无工作或掉落行为。HUD 的 hover 文本属于原生 hoverer 子树，必须在 hoverer 更换和 Wildwise HUD 销毁时分别清理，不能仅依赖自有 Widget 子树释放。

关键边界均配有中文注释。`tests/engine_*.lua` 是开发者主动执行的专服测试入口，普通启动不会加载，发布包不含测试代码。

## 新增模块的约定

1. 先明确服务端事实、客户端偏好和持久数据的归属；将规则放在 `services`，事件与原版方法调用放在 `runtime`，由 bootstrap／世界组件统一接入。无需为了七个模块引入动态插件容器或全局扫描。
2. 新信息字段先定义 schema、类别、单位和查看者依赖，再接入相应隔离读取器；同步 formatter／中英文文案。读取不能修改游戏机制，未知有副作用的 getter 不用于预测。
3. 新增公开配置同步原生平铺字段、内部模块路径、校验枚举、菜单、翻译、两份 README 示例和配置合约。服务器权限必须再次校验，不能只隐藏客户端控件。
4. 新通信遵守现有协议预算和会话边界；实体传引擎引用，持久 ID 不用 GUID。新持久格式给出版本与失败保留策略，不直接覆盖无法识别的旧数据。
5. 监听、周期任务、临时实体和包装器都交由 lifetime 管理。新增循环明确数量／时间上限；优先事件和增量更新，测量后再引入额外索引。
6. 用可观察失效条件写回归：错误输入、旧回调、权限撤销、实体失效、存档恢复和内部模块交互。真实组件测试放在隔离引擎入口；不能自动验证的图形／联机场景写明步骤和待执行状态。

源码使用 Lua 5.1；空行不影响语义。公共方法使用中文说明职责及关键约束，命名函数之间留空行。固定 StyLua 2.5.2、四空格、120 列、不压缩函数体；`npm run format` 格式化，`npm run check` 检查格式、luacheck、回归与发布文件。当前模块接口是仓库内部约定，不宣称稳定的外部插件 SDK。
