# 工坊问题的实机回归用例

日期：2026-09-14。以下用例已经建立，状态均为 **待执行**。当前只有 Linux 无画面专服；纯 Lua 与专服自动测试的通过不能填成这些用例通过。问题编号见[工坊审查](workshop-issues.md)，自动化入口见[测试报告](testing.md)。

统一前置：使用备份后的隔离 cluster；记录 Wildwise 版本、DST 分支／版本／build、Master/Caves、角色、设置和已启用模组。先只开 Wildwise。需要多人时使用本地主机和至少一名真实远程玩家，不用生成的 Wilson 代替。每次保存实际操作、客户端／对应 shard 日志和必要截图；记录数量、坐标、权限等预期值。
